# AITH Search

Репозиторий с домашними работами по курсу AITH Search.

## Оглавление

- [DZ0](dz0/) — формализация критериев оценки веб-поисковиков.
- [DZ1](dz1/) — анализ коллекции WikIR en1k, статистика корпуса, морфологическая обработка и дополнительные эксперименты с авторами и сгенерированными текстами.
- [DZ2](dz2/) — лексический поиск, TF-IDF/BM25, настройка BM25, эксперименты на WikIR, MIRAGE и корпусе Толстого/Достоевского.
- [DZ3](dz3/) — learning-to-rank: CatBoostRanker, MS LETOR, Internet Mathematics 2009, WikIR и MIRAGE.
- [DZ4](dz4/) — dense retrieval, neural re-ranking и смесь BM25 с dense-моделью для WikIR и MIRAGE.
- [DZ5](dz5/) — question answering для MIRAGE: подготовка данных, extractive QA, LLM QA, метрики и итоговые сравнения.

## Что не включается в репозиторий

В `.gitignore` исключены локальные окружения, системные файлы, кеши, модели, крупные сырые датасеты и тяжёлые промежуточные артефакты. В репозитории остаются код, ноутбуки, отчёты, компактные таблицы и графики, которые нужны для проверки решений.
