# Данные для ДЗ2

Чтобы не дублировать крупные файлы, в `dz2` используем уже существующую локальную копию `wikIR1k` из предыдущей работы.

Основной источник: локальная копия `wikIR1k` из `dz1`.

Ожидаемая структура:

- `documents.csv`
- `train/queries.csv`
- `train/qrels`
- `validation/queries.csv`
- `validation/qrels`
- `test/queries.csv`
- `test/qrels`

Если позже понадобится полностью изолировать `dz2`, можно будет либо:

- скопировать эти файлы в `dz2/data/`;
- либо добавить скрипт скачивания и распаковки.

Пока рабочее решение проще и чище: хранить в `dz2` только код, отчёт и артефакты экспериментов.
